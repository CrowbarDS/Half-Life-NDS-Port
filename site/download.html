Before you start

What you need

Your own Half-Life

Any PC copy, such as the Steam one. The converter reads its valve folder. No game files come with this project.

An SD card

The card your console boots homebrew from, plugged into your computer. The full game takes about 700 MB.

A homebrew loader

TWiLight Menu++ on a DSi or 3DS, or a flashcart's menu. The game runs as a normal .nds file.

Installation

Set it up on your computer

  1. Unzip the package

    Right-click the downloaded .zip and choose Extract All. Keep the files together: the program needs the files beside it.

  2. Run the converter

    Open hlds-convert-gui.exe in the extracted folder. If Windows SmartScreen says it protected your PC, choose More info, then Run anyway: the program isn't signed by a paid certificate.

  3. Choose your game, your card and your console

    The converter looks for Half-Life and for your SD card by itself. Check both, say which console the card is for (DSi, 3DS, DS or flashcard, or an emulator), then start. It writes the game's data and the ROM, made for that console, to the card.

  4. Play

    Eject the card safely, put it in your console, and start half-life-nds-port.nds from your loader.

Which processor do I have?

Open Settings > System > About and read System type.

  • 64-bit operating system, x64-based processor: take x64. Almost every Windows PC is this one.
  • ARM-based processor (Snapdragon laptops, Surface Pro X): take ARM64.
  • 32-bit operating system: take x86 (32-bit).
Command line on Windows

The same folder has hlds-convert.exe. In PowerShell, from that folder:

.\hlds-convert.exe cook-all "C:\Program Files (x86)\Steam\steamapps\common\Half-Life\valve" -o E:\ --device dsi

Replace E:\ with your SD card's drive.

--device says which console the card is for: dsi, 3ds (TWiLight Menu++ then offers the wide screen), ds (a DS, DS Lite or DS flashcard; the default) or emulator. A card already converted gets only the ROM, made for its console, with put-rom -o <card> --device <console>.

  1. Unzip the package

    Double-click the downloaded .zip. You get hlds-convert-gui.app; you can move it to Applications.

  2. Open it the first time

    The app isn't signed by an Apple developer account, so macOS stops a double-click. Right-click (or Control-click) the app and choose Open, then Open again. On recent macOS, if there is no Open button, go to System Settings > Privacy & Security and choose Open Anyway.

  3. Choose your game, your card and your console

    The converter looks for Half-Life and for your SD card by itself. Check both, say which console the card is for (DSi, 3DS, DS or flashcard, or an emulator), then start. It writes the game's data and the ROM, made for that console, to the card.

  4. Play

    Eject the card in Finder, put it in your console, and start half-life-nds-port.nds from your loader.

Apple silicon or Intel?

Either. The macOS package is universal: the same app runs natively on Apple silicon (M1 and later) and on Intel Macs, from macOS 12 Monterey.

Command line on macOS

Unpack the command-line package and run it from Terminal. The first run may need the quarantine flag removed:

mkdir hlds-convert && tar -xzf hlds-convert-*-cli-macos-universal.tar.gz -C hlds-convert
xattr -dr com.apple.quarantine hlds-convert
./hlds-convert/hlds-convert cook-all ~/Library/Application\ Support/Steam/steamapps/common/Half-Life/valve -o /Volumes/SDCARD --device dsi

--device says which console the card is for: dsi, 3ds (TWiLight Menu++ then offers the wide screen), ds (a DS, DS Lite or DS flashcard; the default) or emulator. A card already converted gets only the ROM, made for its console, with put-rom -o <card> --device <console>.

  1. Make the AppImage runnable

    In your file manager, open the file's properties and allow it to run as a program, or in a terminal:

    chmod +x hlds-convert-*.AppImage

  2. Run the converter

    Double-click it, or run ./hlds-convert-*.AppImage. AppImages need FUSE 2: if it refuses to start, install libfuse2 (libfuse2t64 on Ubuntu 24.04 and later), or run it with --appimage-extract-and-run.

  3. Choose your game, your card and your console

    The converter looks for Half-Life and for your mounted SD card by itself. Check both, say which console the card is for (DSi, 3DS, DS or flashcard, or an emulator), then start. It writes the game's data and the ROM, made for that console, to the card.

  4. Play

    Unmount the card, put it in your console, and start half-life-nds-port.nds from your loader.

Which processor do I have?

Run uname -m. x86_64 means x86_64; aarch64 means ARM64 (Raspberry Pi 4 and 5 on a 64-bit system, ARM laptops).

Command line on Linux

The command-line package is a static program with no dependencies, good for headless machines:

mkdir hlds-convert && tar -xzf hlds-convert-*-cli-linux-*.tar.gz -C hlds-convert
./hlds-convert/hlds-convert cook-all ~/.steam/steam/steamapps/common/Half-Life/valve -o /media/$USER/SDCARD --device dsi

--device says which console the card is for: dsi, 3ds (TWiLight Menu++ then offers the wide screen), ds (a DS, DS Lite or DS flashcard; the default) or emulator. A card already converted gets only the ROM, made for its console, with put-rom -o <card> --device <console>.

Questions

Where is the ROM?

No: the converter puts the ROM on the card for you, made for the console you choose. For a card that already has the game converted, the command line writes the ROM alone: hlds-convert put-rom -o <card> --device <console>. Keep the ROM and the converter from the same release: the title screen shows the version at the bottom, and warns you if the card's data came from a different one.

How do I update?

Download the new converter and run it again on the same card. It brings the ROM and the game's data up to the new version.

How do I check a download?

Compare the file's SHA-256 with the line for it in SHA256SUMS.txt.

# Linux
sha256sum -c --ignore-missing SHA256SUMS.txt
# macOS
shasum -a 256 -c --ignore-missing SHA256SUMS.txt
# Windows PowerShell
Get-FileHash .\hlds-convert-*.zip -Algorithm SHA256
Multiplayer without a card?

A console with no card can join a game by Download Play: the host, which has the ROM and the converted game, sends it over the air.
